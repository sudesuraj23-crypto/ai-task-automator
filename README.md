🚀 Quick Start
1. Clone the repository
git clone https://github.com/sudesuraj23-crypto/ai-task-automator.git
cd ai-task-automator
2. Install dependencies
pip install -r requirements.txt
3. Run the app
python main.py
4. Enter your Claude API key when prompted
Get your free API key at 👉 console.anthropic.com
